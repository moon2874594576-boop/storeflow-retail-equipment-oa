# 来源与改造对照

上游：[Enterprise OA](https://github.com/yanyihao-han/enterprise-oa)。基准提交：`c4a8df979a723ec9bf71e8cdd63dbbdcab14a678`。通过该提交公开源码归档导入，本仓库保留基线提交。上游 README 声明 MIT，获取的基线没有单独 LICENSE 文件；保留其声明，不替上游补写许可证文本。

项目目录、Django/DRF 与 Vue/Element Plus 基础、账号角色模型和部分组件来自上游。旧代码可以通过基线查看，不能将复用内容描述为独立从零开发。

| 原项目 | StoreFlow 改造 |
|---|---|
| 请假、报销、出差通用表单 | 门店设备临时借用的专用字段与验证 |
| 审批通过即结束 | 审批、发放、签收、归还验收连续流转 |
| 没有设备资源 | 编号、类别、占用和待维修状态 |
| 管理接口主要检查登录 | 角色、门店、归属和动作状态联合校验 |
| 普通编辑可触及审批状态 | 关键状态仅通过动作维护 |
| 通用管理界面 | 以角色待办和设备去向组织工作台 |
| 本地开发说明 | PyCharm、离线前端、容器、备份恢复、测试证据 |

实际贡献以仓库差异和测试为准。门店、账号、设备均为虚构，不含朴朴内部系统或真实业务数据；演示结果不表述为企业上线业绩。
